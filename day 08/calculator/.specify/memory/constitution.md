# Simple Calculator Constitution

## Core Principles

### Simplicity and Focus
The calculator MUST only provide basic arithmetic operations (addition, subtraction, multiplication, division). No advanced functions (e.g., trigonometry, exponents, memory) are permitted to maintain a clear and simple user experience.

### Accuracy and Reliability
All calculations MUST produce mathematically correct results. Error handling for invalid inputs (e.g., division by zero) MUST be robust and user-friendly.

### User Experience (UX)
The user interface MUST be intuitive and easy to navigate. Input and output MUST be clear and unambiguous.

## Governance

Amendments to this constitution MUST follow a formal review and approval process by project maintainers. All changes MUST be backward-compatible with the core principles unless a major version bump is explicitly justified.

Constitution versions follow semantic versioning. MAJOR for incompatible changes, MINOR for new principles/sections, PATCH for clarifications/typos.

Compliance with these principles WILL be reviewed quarterly and before major releases.
